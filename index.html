Términos de Servicio Política de Privacidad

Términos de Servicio

Estos Términos regulan el uso del bot de Discord L8 niño polla (“el Bot”).

1. Uso del Bot

El Bot proporciona funciones para servidores de Discord, incluyendo creación y gestión de canales de voz (VC), registro y cálculo del tiempo de permanencia en canales de voz y un sistema de acumulación de horas de actividad.

2. Uso adecuado

No debes utilizar el Bot para actividades ilegales, abusivas, fraudulentas o que infrinjan las reglas de Discord. Tampoco debes intentar obtener acceso no autorizado a cuentas, servidores o información.

3. Disponibilidad

El Bot se proporciona tal como está disponible. Sus funciones pueden modificarse, suspenderse o retirarse en cualquier momento. No se garantiza disponibilidad permanente ni ausencia de errores.

4. Datos

El Bot puede procesar determinados datos necesarios para sus funciones. El tratamiento se explica en la Política de Privacidad de esta página.

5. Discord

L8 niño polla es un servicio independiente y no está operado ni patrocinado por Discord. El uso de Discord está sujeto a sus propios términos y políticas.

Política de Privacidad

Esta Política explica qué información puede procesar L8 niño polla, para qué se utiliza y cómo solicitar su eliminación.

1. Información que podemos recopilar

  • ID de usuario de Discord.
  • ID del servidor de Discord.
  • ID de los canales de voz utilizados por el Bot.
  • Nombre o identificador necesario para mostrar estadísticas.
  • Hora de entrada y salida de un canal de voz.
  • Tiempo acumulado de permanencia en canales de voz.
  • Información necesaria para ejecutar comandos.

El Bot no graba ni almacena el contenido de las conversaciones de voz.

2. Finalidad

Los datos se utilizan para crear y administrar canales de voz, calcular horas de actividad, mantener estadísticas, ejecutar comandos, solucionar errores y detectar abusos.

3. Compartición

No vendemos los datos recopilados. No los compartimos con terceros salvo cuando sea necesario para prestar el servicio, cumplir obligaciones legales o proteger la seguridad del Bot y sus usuarios.

4. Conservación

Conservamos los datos durante el tiempo necesario para proporcionar las funciones del Bot y mantener sus estadísticas. Cuando dejan de ser necesarios, pueden eliminarse o anonimizarse.

5. Eliminación

Puedes solicitar la eliminación de los datos asociados a tu cuenta de Discord escribiendo a [TU CORREO]. Incluye tu ID de usuario de Discord para localizar los datos correspondientes.

6. Seguridad

Tomamos medidas razonables para proteger la información procesada frente a accesos no autorizados, pérdida o uso indebido.

7. Cambios

Esta Política puede actualizarse cuando sea necesario. La fecha de actualización aparecerá al principio de la página.
