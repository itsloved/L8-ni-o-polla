# L8 Niño polla

Bot original de Discord con comandos slash, creación de canales de voz y registro de horas.

1. Instala Node.js 24.17+.
2. Ejecuta `npm install`.
3. Copia `.env.example` a `.env` y completa el token, Client ID y Server ID.
4. Ejecuta `npm run deploy`.
5. Ejecuta `npm start`.

Nunca publiques el token del bot.
